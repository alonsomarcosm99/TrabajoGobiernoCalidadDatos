# Publicación documental

El workflow `.github/workflows/pages.yml` construye el repositorio con Jekyll y publica el resultado en `https://alonsomarcosm99.github.io/TrabajoGobiernoCalidadDatos/`.

La web es evidencia documental. La reproducción operativa de OpenMetadata sigue los scripts del repositorio y requiere un entorno local controlado.
